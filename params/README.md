# 設定ファイルの説明（学生向け）

このフォルダには、間隙水圧計のデータを「どう読むか」「どう計算するか」「グラフをどう描くか」を決める設定が入っています。

## ファイルの役割

| ファイル | 役割 |
|----------|------|
| **base.yaml** | 全実験（ケース）で共通の設定。データの読み方・基準の取り方・フィルタ・グラフの見た目など。 |
| **cases/*.yaml** | 実験ごとの設定（任意）。書いた項目だけ base.yaml を上書きします。例：チャンネルと列の対応、DIP除去のON/OFF。 |

## 設定を変えるとき

1. **まず base.yaml を開く**  
   項目ごとに「【意味】」のコメントがあるので、何を変えているか確認しながら編集できます。
2. **1つの実験だけ変えたいとき**  
   `cases/{その実験のケース名}.yaml` を作成または編集します。例：`No7-incline-8mm` だけ変えたい → `cases/No7-incline-8mm.yaml`。
3. **変更を反映する**  
   ノートブックのセルを実行し直すか、ターミナルで `poreviz run` を再度実行します。

## よく触る項目（base.yaml）

- **io.baseline_seconds** … 「実験の開始」を記録開始から何秒後にするか（例：60）。
- **io.pore_drift_* ** … 間隙水圧のドリフト補正の区間。
- **io.filters.pore** … 間隙水圧のノイズ除去（median_window など）。
- **io.hydraulic_gradient_lengths** … 動水勾配計算用の測定点間距離（装置に合わせて変更）。
- **plot_style.time_from_start_seconds** … グラフの横軸の 0 秒をいつにするか。
- **plot_style.figure** … 図のサイズや dpi（解像度）。

## ケース別設定（cases/*.yaml）でよく使うもの

- **io.channel_mapping** … 計測器のチャンネル（P1, P2, …）と CSV の列番号（0始まり）の対応。実験ごとに接続が違うときに指定。
- **io.pore_dip_removal** … 下向きのトゲ（DIP）を補正するか。その実験だけ有効にしたいときに指定。

詳細は base.yaml の先頭と各項目のコメントを参照してください。
